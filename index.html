Rotavation Trajectory Simulator

Click on the map to mark field vertices. Then close polygon, select base edge and start vertex. Rows are generated inside a field-safe centerline polygon. Optional dark-pink obstacle zones are treated like internal field boundaries, and obstacle-split rows return on the same path. Connectors are routed through the safe headland/perimeter instead of cutting diagonally around wells.

Field parameters

Minimum enforced: R2R × clearance factor.
Machine center stays R2R × factor away from physical field boundary. Default 0.55 is slightly greater than R2R/2.

Obstacles / wells

Optional: add a square or circular obstacle, then drag its pink handle over the well/object. The hashed dark-pink avoidance zone is treated like an internal red boundary. If it cuts a row, the machine goes up to the obstacle boundary and returns on the same path; it will not do a same-row side bypass around the object.

Circle = diameter, square = side length.
Obstacle safety margin uses the same clearance: R2R × boundary clearance factor. The pink outer line is the no-go boundary for the machine centerline.
